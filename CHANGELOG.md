# Changelog

## 0.1.0 — initial implementation

- Native Windows subtitle search from the classic Explorer context menu.
- Hash-first search with title fallback using the anonymous VLSub protocol.
- All provider languages, cached catalog and remembered default language.
- English and Brazilian Portuguese interface and installer.
- Safe subtitle decoding and no-overwrite saving next to the video.
- Self-contained build, per-user installer, deterministic tests and GitHub Actions.
