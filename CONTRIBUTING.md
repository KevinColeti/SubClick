# Contributing

Read `docs/DEVELOPMENT.md`, keep changes focused and run `./build.ps1` before submitting. Include reproduction steps for bugs and describe manual UI/installer checks when relevant. Do not include private video paths, account details or downloaded copyrighted subtitle files in issues or fixtures.

New code is contributed under GPL-3.0-or-later. Preserve third-party copyright and license notices. Network access must keep certificate validation enabled; service errors must be visible rather than bypassed.
